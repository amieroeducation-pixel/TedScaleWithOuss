## 🚀 Prochaines Étapes (IMPORTANT)

### Étape 1 : Configurer les cron jobs (10 min)

**Tu DOIS faire ça une fois pour que les rappels SMS fonctionnent !**

1. **Ouvre PowerShell en administrateur** :
   - Appuie sur **Windows**
   - Tape **"PowerShell"**
   - **Clic droit** → "Exécuter en tant qu'administrateur"

2. **Navigue vers le projet** :
   ```powershell
   cd "C:\Users\Ted\Documents\Obsidian Vault\TedScaleWithOuss"
   ```

3. **Exécute le script** :
   ```powershell
   .\setup-task-scheduler.ps1
   ```

4. **Vérifie que les 5 tâches sont créées** :
   ```powershell
   Get-ScheduledTask | Where-Object { $_.TaskName -like 'TedScale_*' }
   ```

Tu devrais voir :
- `TedScale_RdvReminder` (toutes les 30 min)
- `TedScale_SequencesProcess` (toutes les 5 min)
- `TedScale_NurturingTemperature` (toutes les heures)
- `TedScale_ClientHealth` (1x par jour)
- `TedScale_WeeklyReport` (1x par jour)
